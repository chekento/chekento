# Chroma Clash — Datenschutzerklärung / Privacy Policy

**Stand / Last updated: 21 August 2026**  
**App:** Chroma Clash  
**Android package:** `cloud.kosch.chromaclash`

## Deutsch

Chroma Clash ist als Offline-First-Android-Spiel konzipiert. Die aktuelle Version verarbeitet keine personenbezogenen Daten auf Servern des Entwicklers oder von Drittanbietern.

### Datenerhebung und Datenweitergabe

Die aktuelle Version von Chroma Clash erhebt, überträgt oder teilt keine personenbezogenen Daten.

- Es ist kein Benutzerkonto erforderlich.
- Es ist kein Analyse- oder Tracking-SDK integriert.
- Es ist kein Werbe-SDK integriert.
- Es werden keine Tracking-Pixel verwendet.
- Für das Spielen ist kein externer KI-, Cloud- oder API-Dienst erforderlich.
- Die App fordert keine Android-Laufzeitberechtigungen an.
- Es werden keine personenbezogenen Daten an andere Unternehmen oder Organisationen weitergegeben.

### Lokal gespeicherte Spieldaten

Spielfortschritt, Ränge, Achievements, Punktestände, Serien und Einstellungen werden ausschließlich lokal auf dem Gerät im Speicher der Android-WebView gespeichert. Die Android-App-Sicherung ist für die Release-Version deaktiviert.

Beim Deinstallieren der App oder Löschen ihrer App-Daten können diese lokal gespeicherten Fortschrittsdaten dauerhaft verloren gehen.

### Konten und Kinder

Chroma Clash bietet keine Benutzerkonten, keine soziale Anmeldung und keine vom Entwickler betriebenen Nutzerprofile. Da die aktuelle Version keine personenbezogenen Daten erhebt, werden auch keine personenbezogenen Daten von Kindern oder Erwachsenen erhoben.

### Änderungen dieser Datenschutzerklärung

Falls zukünftige Versionen Online-Dienste, Analysen, Werbung, Benutzerkonten, Cloud-Speicher oder andere Funktionen zur Datenverarbeitung hinzufügen, wird diese Datenschutzerklärung vor Veröffentlichung entsprechend aktualisiert. Gleiches gilt für die Angaben im Bereich „Datensicherheit“ von Google Play.

### Kontakt

Fragen zu dieser Datenschutzerklärung können über die im Google-Play-Eintrag von Chroma Clash veröffentlichten Entwickler-Kontaktdaten gestellt werden.

## English

Chroma Clash is designed as an offline-first Android game. The current release does not process personal data on developer-operated or third-party servers.

### Data collection and sharing

The current release of Chroma Clash does not collect, transmit or share personal data.

- No user account is required.
- No analytics or tracking SDK is included.
- No advertising SDK is included.
- No tracking pixels are used.
- No external AI, cloud or API service is required for gameplay.
- The app requests no Android runtime permissions.
- No personal data is shared with other companies or organizations.

### Locally stored game data

Game progress, ranks, achievements, scores, streaks and settings are stored only on the user's device in Android WebView storage. Android application backup is disabled for the release build.

Uninstalling the app or clearing its application data may permanently remove this locally stored progress.

### Accounts and children

Chroma Clash does not provide user accounts, social login or developer-operated user profiles. Because the current release does not collect personal data, it does not collect personal data from children or adults.

### Changes to this policy

If future versions add online services, analytics, advertising, accounts, cloud saves or other data-processing features, this policy will be updated before release. The Google Play Data Safety declaration will be updated as well.

### Contact

Questions about this privacy policy can be submitted using the developer contact information published with Chroma Clash on Google Play.
