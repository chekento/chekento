# K Android 1.0 · Companion Audio Bridge

Build source for the K Android / Total Launcher audio-reactive companion mouth.

The Android helper captures allowed playback audio via AudioPlaybackCapture, analyzes 15 frequency bands at 48 kHz, and renders a single-row LCARS EQ mouth. It also includes a microphone fallback and an AI/Compliance news reader.

The source archive in this folder is built automatically by GitHub Actions on the `k-android-bridge` branch.
